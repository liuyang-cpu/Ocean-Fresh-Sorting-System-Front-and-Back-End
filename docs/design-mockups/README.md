# 功能规格设计图

本目录保存基于 `docs/功能规格说明书.md` 生成的 Figma 风格视觉稿，用于功能评审、界面方向讨论和后续前端还原参考。

## 文件清单

- `home-monitoring-figma-mockup.png`：首页 / 生产监控一体化界面，突出 X 光图像、识别结果、状态记录和主控操作。
- `data-center-figma-mockup.png`：数据中心界面，突出海鲜产品维度、良率趋势、缺陷分布和检测任务记录。
- `settings-center-figma-mockup.png`：设置中心界面，突出产品、模型、通道、硬件、剔除、系统设置入口。
- `user-center-figma-mockup.png`：用户中心界面，突出当前用户、权限范围和管理员密码修改。

## 使用说明

这些图片是视觉概念稿，不是可编辑的 `.fig` 文件。若要落地到可交互界面，建议以当前 Vue / Electron HMI 作为实现目标，按页面逐步还原布局、色彩、组件层级和状态反馈。
