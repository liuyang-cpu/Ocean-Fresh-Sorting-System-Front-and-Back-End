# 开题报告用例图说明

本文档基于 `功能规格说明书.md`（V1.1，2026-06-29）整理，用于开题报告中“系统用例分析”章节。建议先给出总体用例图，再按业务模块逐一说明各子用例图。

## 1. 系统总体用例图

总体用例图用于说明系统边界、主要参与者和主导航功能。系统参与者包括操作员、管理员、X 光采集链路、YOLO 推理服务以及 PLC / 剔除控制器。操作员主要完成生产检测、数据查看和用户信息查看；管理员在操作员能力基础上进一步维护产品、模型、通道、硬件、剔除控制、安全预警和软件维护。

- 源文件：`puml/usecase-00-system-overview.puml`
- PDF：`pdf/usecase-00-system-overview.pdf`
- 图片：`png/usecase-00-system-overview.png`

## 2. 首页生产检测用例图

首页生产检测用例图对应系统的核心生产流程。操作员先配置数据源，可选择 `X 光相机` 或 `本地图片目录`。机器启动后系统创建或进入检测任务，并按当前启用通道绑定的产品、模型和阈值执行检测。X 光相机模式允许联动剔除设备；本地图片目录模式只进行离线检测分析和统计，不输出真实剔除动作。

- 源文件：`puml/usecase-01-production-detection.puml`
- PDF：`pdf/usecase-01-production-detection.pdf`
- 图片：`png/usecase-01-production-detection.png`

## 3. 数据中心与异常复核用例图

数据中心用例图用于说明历史数据查看、检测任务记录和异常复核。操作员可以按海鲜产品和时间范围查看良率、缺陷排行、趋势分析与任务明细。管理员可以对模型判定为异常的剔除集合 `S` 进行复核，复核结果包括确认异常、误剔和类别修正，并进一步计算异常确认率、误剔率和类别修正数量。

- 源文件：`puml/usecase-02-data-review.puml`
- PDF：`pdf/usecase-02-data-review.pdf`
- 图片：`png/usecase-02-data-review.png`

## 4. 产品、模型与通道配置用例图

产品、模型与通道配置用例图描述管理员在产品设置中的维护工作。管理员可维护海鲜产品、正常项与缺陷项、`classes.txt` 标签文件以及模型标签到业务性状的映射；可导入 YOLO 权重文件、维护模型版本；还可配置通道绑定的产品、模型和置信度阈值。该图强调模型被通道使用时不可删除，且机器运行期间不可切换当前启用通道。

- 源文件：`puml/usecase-03-product-model-channel.puml`
- PDF：`pdf/usecase-03-product-model-channel.pdf`
- 图片：`png/usecase-03-product-model-channel.png`

## 5. 硬件、剔除控制与安全预警用例图

硬件、剔除控制与安全预警用例图描述管理员对 X 光光源、X 光探测器、传送带、剔除设备和 PLC / 剔除控制器的管理。系统支持刷新设备状态、设备自检、维护剔除方式和剔除动作参数，并在关键硬件异常时进入故障状态，阻断机器正常运行。

- 源文件：`puml/usecase-04-hardware-ejection-safety.puml`
- PDF：`pdf/usecase-04-hardware-ejection-safety.pdf`
- 图片：`png/usecase-04-hardware-ejection-safety.png`

## 6. 用户中心与权限管理用例图

用户中心与权限管理用例图用于说明系统的角色访问边界。操作员无密码进入系统，可访问首页、用户、数据和退出系统；管理员通过密码登录，可进入设置页并维护系统配置。用户中心显示当前角色、账号、登录时间和权限范围，管理员还可以修改管理员密码。

- 源文件：`puml/usecase-05-user-permission.puml`
- PDF：`pdf/usecase-05-user-permission.pdf`
- 图片：`png/usecase-05-user-permission.png`

## 7. 算法训练服务三阶段优化用例图

算法训练服务用例图基于远端训练工作流 `Seafood-Defect-Detection-Workflow/src/scheduler-final` 整理。该服务面向算法工程师，负责串联基础训练配方优化、注意力结构消融和选中结构二次优化三个阶段。阶段一通过 Optuna 与 LLM 循环优化基础 YOLO11n 训练配方；阶段二基于最佳配方生成注意力结构配置并比较基线、CBAM、ECA 等结构；阶段三对选中的非基线结构再次进行参数搜索，最终沉淀最佳配方、最佳结构、候选模型权重、实验报告和工作流汇总。

- 源文件：`puml/usecase-06-algorithm-training-workflow.puml`
- PDF：`pdf/usecase-06-algorithm-training-workflow.pdf`
- 图片：`png/usecase-06-algorithm-training-workflow.png`
