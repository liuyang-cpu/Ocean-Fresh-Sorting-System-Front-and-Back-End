# Ocean Fresh 无硬件接入版运行说明

## 1. 版本用途

本文档对应 Git 分支：

```text
codex/teacher-delivery-clean-20260918
```

该分支是一份独立的对外交付快照，不包含开题报告资料和现场硬件适配开发历史。

这是现场硬件适配开发之前的软件版本，适合进行课程检查、源码阅读和离线图片推理演示。

本版本已经包含：

- Windows WPF 操作界面；
- ASP.NET Core 本地 API；
- SQLite 数据库及自动初始化；
- 海鲜产品、缺陷类别、模型和通道管理；
- YOLO FastAPI 推理服务；
- 本地图片目录检测；
- 检测记录、统计分析、人工复核、用户和报警功能；
- 传送带、X 光探测器、剔除设备等业务模型及模拟接口。

本版本不包含：

- Techik 探测器 SDK 接入；
- `TechikDetectorBridge.exe` 原生桥接；
- 现场 COM1、COM3、COM5 设备连接；
- X 光源、传送带和 IO 模块的真实控制；
- 真实喷嘴输出；
- Fintek 串口驱动或其他 Windows 内核驱动开发。

因此，本版本只能进行软件功能和离线图片推理演示，不能控制现场机器。

## 3. 运行环境

推荐环境：

- Windows 10 或 Windows 11，64 位；
- .NET SDK 8.0；
- Python 3.11，64 位；
- Git；
- NVIDIA 显卡可选，没有显卡时可以使用 CPU 推理，但速度较慢；
- Visual Studio 2022 可选，使用命令行即可构建。

检查环境：

```powershell
dotnet --version
python --version
git --version
```

`.NET` 版本应以 `8.` 开头。推荐 Python 版本为 `3.11.x`。

首次执行 `dotnet restore` 和 `pip install` 需要联网下载 NuGet 包与 Python 包。如果目标电脑离线，需要提前准备好 NuGet 缓存、Python 离线依赖或已制作的 Windows 发布包；仅拷贝 Git 源码无法在一台全新且完全离线的电脑上自动安装这些依赖。

## 4. 安装 Python 推理环境

在仓库根目录打开 PowerShell：

```powershell
py -3.11 -m venv .venv
```

如果系统没有 `py` 命令，可以使用：

```powershell
python -m venv .venv
```

激活环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

如果 PowerShell 阻止脚本执行，可只对当前窗口临时放开：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
```

安装依赖：

```powershell
python -m pip install --upgrade pip
pip install -r predict\youge\service\requirements.txt
```

验证依赖：

```powershell
python -c "import torch, ultralytics, fastapi, uvicorn; print('Python inference environment: OK'); print('torch=', torch.__version__); print('cuda=', torch.cuda.is_available())"
```

设置当前 PowerShell 会话使用的 Python：

```powershell
$env:OCEANFRESH_YOLO_PYTHON="$PWD\.venv\Scripts\python.exe"
```

该设置只对当前 PowerShell 窗口有效。重新打开终端后需要再次设置。

## 5. 构建和测试

首次拉取代码后，不要使用 `--no-restore`。执行：

```powershell
dotnet restore OceanFresh.SortingSystem.sln
dotnet build OceanFresh.SortingSystem.sln
dotnet test tests\OceanFresh.SortingSystem.Tests\OceanFresh.SortingSystem.Tests.csproj --no-build
```

如果构建时提示 HMI 或 LocalApi 文件被占用，请先退出已经运行的软件，再重新构建。

## 6. 启动方式

### 6.1 推荐方式：分别启动三个进程

这种方式最适合首次运行，因为可以直接看到各服务的错误信息。

#### 终端一：启动 YOLO 服务

在仓库根目录执行：

```powershell
$env:OCEANFRESH_YOLO_PYTHON="$PWD\.venv\Scripts\python.exe"
predict\yolo\service\start_yolo_service.bat
```

YOLO 服务默认地址：

```text
http://127.0.0.1:8010
```

浏览器访问以下地址，能够返回正常结果即表示服务已启动：

```text
http://127.0.0.1:8010/health
```

#### 终端二：启动 LocalApi

```powershell
dotnet run --project src\OceanFresh.SortingSystem.LocalApi
```

LocalApi 默认地址：

```text
http://127.0.0.1:5188
```

可以访问以下地址检查运行状态：

```text
http://127.0.0.1:5188/api/runtime/snapshot
```

#### 终端三：启动 WPF 软件

```powershell
dotnet run --project src\OceanFresh.SortingSystem.HMI
```

### 6.2 简化方式：只启动 HMI

完成解决方案构建并设置 Python 路径后，也可以执行：

```powershell
$env:OCEANFRESH_YOLO_PYTHON="$PWD\.venv\Scripts\python.exe"
dotnet run --project src\OceanFresh.SortingSystem.HMI
```

HMI 会尝试自动启动已经构建好的 LocalApi 和 YOLO 服务。如果自动启动失败，请改用 6.1 节的三个终端方式查看具体错误。

## 7. 登录方式

操作员登录不需要密码，直接点击“操作员登录”。

默认管理员密码：

```text
admin123
```

管理员登录后可以进入产品、模型、通道、设备、用户和软件设置页面。第一次演示后可以在用户中心修改管理员密码。

## 8. 数据库和运行数据

系统使用 SQLite，不需要单独安装 MySQL 或 SQL Server。首次启动 LocalApi 时会自动初始化数据库。

默认数据目录为：

```text
%LOCALAPPDATA%\OceanFreshSortingSystem
```

数据库文件为：

```text
%LOCALAPPDATA%\OceanFreshSortingSystem\oceanfresh.db
```

为了让演示数据保存在仓库旁边，可以在启动 LocalApi 和 HMI 前分别设置相同的数据目录：

```powershell
$env:OCEANFRESH_DATA_ROOT="$PWD\runtime-data"
```

如果采用三个终端启动，应在启动 LocalApi 和 HMI 的两个终端中都设置该变量。

`runtime-data` 是运行产物，不应提交到 Git。

## 9. 模型和演示资源

本分支已包含一份油蛤 YOLO11n 权重和三种产品的标准类别文件：

```text
deployment-assets
└─ yolo
   ├─ youge
   │  ├─ best.pt
   │  └─ classes.txt
   ├─ meibei
   │  └─ classes.txt
   └─ huage
      └─ classes.txt
```

对应关系为：

- `deployment-assets\yolo\youge\classes.txt`：油蛤，类别顺序为 `broken / normal / muddy / empty`；
- `deployment-assets\yolo\meibei\classes.txt`：美贝，与油蛤使用相同类别顺序；
- `deployment-assets\yolo\huage\classes.txt`：花蛤，类别顺序为 `broken / normal / sandy / empty`。

仓库中只包含油蛤权重，花蛤和美贝的真实模型权重仍需另行提供。要演示离线图片推理，还需要准备一小批 JPG、PNG、BMP 或 TIFF 测试图片。

## 10. 首次配置和离线图片推理

### 10.1 创建产品

1. 使用管理员账号登录；
2. 进入“设置”；
3. 打开“产品管理”；
4. 新建海鲜产品；
5. 从 `deployment-assets\yolo` 中选择对应产品目录下的 `classes.txt`；
6. 设置正常类别和异常类别；
7. 保存产品。

### 10.2 导入模型

1. 打开“模型管理”；
2. 演示油蛤时选择 `deployment-assets\yolo\youge\best.pt`；花蛤或美贝需选择另行提供的对应 `.pt` 或 `.onnx` 权重；
3. 选择刚才创建的产品；
4. 填写训练图像尺寸，通常为训练时使用的 `imgsz`，例如 `640`；
5. 保存模型。

### 10.3 创建并启用通道

1. 打开“通道配置”；
2. 新建或编辑通道；
3. 选择产品和模型；
4. 设置置信度阈值；
5. 启用该通道；
6. 保存配置。

至少需要一个启用的通道，并且该通道必须绑定有效模型，否则无法开始推理。

### 10.4 使用本地图片演示

1. 回到主页面；
2. 将数据源切换为“本地图片目录”；
3. 选择 `teacher-demo-assets\test-images`；
4. 设置图片间隔；
5. 点击“启动设备”或开始检测；
6. 查看检测图像、检测框、类别、置信度及统计结果。

本地图片目录模式不会执行真实剔除，也不会控制任何现场硬件。

## 11. 推荐验收流程

老师拉取代码后，可以按照以下顺序检查：

1. `dotnet build` 构建成功；
2. `dotnet test` 测试通过；
3. YOLO `/health` 正常；
4. LocalApi `/api/runtime/snapshot` 正常；
5. HMI 登录页面正常；
6. 操作员和管理员登录正常；
7. 产品、模型和通道可以创建；
8. 本地图片能够依次进入推理；
9. 主页面能够显示图片、检测框和分类结果；
10. 数据中心能够查询检测记录和统计信息。

## 12. 常见问题

### 12.1 `dotnet` 命令不存在

安装 .NET 8 SDK，而不是只安装 .NET Runtime。安装完成后重新打开 PowerShell。

### 12.2 第一次构建提示缺少 NuGet 包

执行：

```powershell
dotnet restore OceanFresh.SortingSystem.sln
```

然后重新构建。

### 12.3 PowerShell 不允许激活虚拟环境

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
```

### 12.4 YOLO 服务没有启动

确认当前终端设置了正确的 Python：

```powershell
$env:OCEANFRESH_YOLO_PYTHON="$PWD\.venv\Scripts\python.exe"
& $env:OCEANFRESH_YOLO_PYTHON -c "import torch, ultralytics, fastapi, uvicorn; print('OK')"
```

然后手动启动服务，以便查看错误：

```powershell
predict\yolo\service\start_yolo_service.bat
```

### 12.5 HMI 提示无法连接本地 API

确认 `http://127.0.0.1:5188/api/runtime/snapshot` 可以访问。如果不能访问，在单独终端执行：

```powershell
dotnet run --project src\OceanFresh.SortingSystem.LocalApi
```

### 12.6 端口被占用

默认端口：

- LocalApi：`5188`；
- YOLO：`8010`。

检查端口：

```powershell
Get-NetTCPConnection -LocalPort 5188,8010 -ErrorAction SilentlyContinue
```

关闭旧的软件进程后再启动。

### 12.7 软件可以打开，但无法推理

依次检查：

- YOLO 服务是否健康；
- 是否已经导入真实模型权重；
- 模型路径是否仍然存在；
- 产品是否配置了正确的 `classes.txt`；
- 是否存在一个已启用并绑定模型的通道；
- 主页面是否选择了包含支持格式图片的目录。

### 12.8 没有 NVIDIA 显卡

可以使用 CPU 完成小规模演示，但推理速度会明显降低。课程功能演示建议只准备少量测试图片。
