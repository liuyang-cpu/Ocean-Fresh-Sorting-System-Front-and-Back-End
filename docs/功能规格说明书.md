# 海鲜 X 光分拣系统功能规格说明书

版本：V1.2  
日期：2026-06-30  
用途：甲方功能确认、阶段性交付说明、后续开发依据

## 1. 文档定位

本文以当前软件界面上可见的导航、页面、按钮和数据面板为主线，说明本系统已经规划和正在交付的功能范围。

当前交付前端以 `WPF HMI` 为准。此前用于验证的 `Electron/Vue` 前端原型暂时保留在工程中，但不作为本阶段甲方验收的主界面口径。

- 左侧主导航：`首页`、`用户`、`数据`、`设置`、`退出系统`。
- 首页主控按钮：`机器启动 / 机器停止` 状态按钮、`数据源配置`。
- 设置页一级导航：`产品设置`、`硬件设置`、`剔除设置`、`系统设置`。
- 设置页二级功能：`海鲜产品`、`模型管理`、`通道配置`、`设备管理`、`剔除控制`、`安全预警`、`软件维护`。

后续真实硬件接入、X 光探测器驱动、PLC 通信、剔除设备控制等内容，会作为这些可见功能背后的实现方式和后续开发规格说明，不单独脱离界面功能描述。

## 2. 当前软件目标

当前软件目标是形成一套可展示、可联调、可继续开发的 Windows 工控机分拣系统。甲方在软件界面上应能看到以下能力：

- 在首页查看当前 X 光图像、AI 识别结果、分类统计、传送带速度、海鲜总数和工作时长。
- 通过首页主控操作台启动或停止机器。
- 通过首页数据源配置选择 `X 光相机` 或 `本地图片目录`；本地图片目录用于离线检测分析，不输出硬件剔除动作。
- 在数据中心按海鲜产品和时间范围查看生产统计、良率趋势和检测任务记录。
- 在用户中心查看当前用户、权限范围，并支持管理员修改密码。
- 在设置页维护海鲜产品、模型、通道、硬件设备、剔除控制、安全预警和软件维护信息。

系统正式生产时，首页应作为常驻页面。操作员主要关注图像、识别结果、数量统计、运行状态和机器启停，不需要看到模型坐标、推理调试日志等开发信息。

| --- | --- | --- |
| 机器启动 / 机器停止 | 一个状态按钮，未运行时显示启动，运行中显示停止 | 正式生产中对应传送带、X 光采集、检测任务等整体启停 |

## 4. 用户角色与权限范围

用户角色的功能范围必须是“可见功能总览”的子集。

| 角色 | 登录方式 | 可访问主导航 | 可操作功能 |
| --- | --- | --- | --- |
| 操作员 | 无密码进入 | 首页、用户、数据、退出系统 | 机器启动、机器停止、配置数据源、查看实时图像、查看识别结果、查看统计数据、查看当前用户和权限 |
| 管理员 | 输入管理员密码进入 | 首页、用户、数据、设置、退出系统 | 操作员全部功能 + 产品设置、模型管理、通道配置、设备管理、剔除控制、安全预警、软件维护、修改管理员密码 |

权限规则：

- 操作员不可进入设置页。
- 操作员不可修改产品、模型、通道、硬件和系统配置。
- 管理员可以进入设置页并维护配置。
- 管理员密码第一版固定账号为 `admin`，默认密码为 `admin123`，可在用户中心修改。

## 5. 首页功能规格

首页是生产常驻页面，合并原“首页”和“监控检测”功能。

### 5.1 食品检测区

展示内容：

- 当前 X 光图像。
- YOLO 检测结果图。
- 当前通道。
- 当前海鲜产品。
- 当前模型版本。
- 当前检测状态。

功能要求：

- 图像显示区域应优先展示 YOLO 带框结果图。
- 若暂无检测结果图，应显示原始 X 光图像或等待提示。
- 检测结果标签必须使用海鲜产品的业务性状名称，例如 `正常`、`碎壳`、`泥包`、`空壳`，不应直接展示 `class_0`。

### 5.2 当前图片识别结果

展示当前图片的四类结果矩阵：

- 正常。
- 碎壳。
- 泥包。
- 空壳。

功能要求：

- 数字应与当前图片识别结果对应。
- 不同性状使用固定颜色，便于操作员快速识别。
- 显示结果必须与当前通道绑定的海鲜产品标签映射一致。

### 5.3 分类统计

展示当前检测任务内的累计分类统计：

- 正常数量。
- 碎壳数量。
- 泥包数量。
- 空壳数量。
- 异常总数。
- 良率。

统计口径：

- 海鲜总数 = 正常数量 + 异常总数。
- 异常总数 = 碎壳 + 泥包 + 空壳等非正常类别数量。
- 良率 = 正常数量 / 海鲜总数。
- 真实剔除命令数 = 实际下发到剔除设备的命令数量，仅生产检测模式可能大于 0。

说明：

- 异常总数应通过图表体现为多个异常类别的总和，不应突兀地作为孤立行显示。
- 本地图片目录模式只统计异常判定，不生成真实剔除命令。
- 若当前产品后续扩展更多缺陷类别，分类统计应按该产品配置动态扩展。

### 5.4 状态记录

展示运行状态指标：

- 传送带速度。
- 海鲜总数。
- 工作时长。

设计说明：

- 传送带速度属于整机/硬件运行参数，不属于通道配置字段。
- 当前阶段可使用系统默认速度展示。
- 真实硬件接入后，传送带速度应优先来自 PLC 或传送带设备实时反馈。

### 5.5 主控操作台

主控操作台显示：

- 机器启动 / 机器停止状态按钮。
- 数据源配置。
- 当前数据源状态。
- 本地图片目录进度。
- 当前运行提示日志。

功能要求：

- 机器启动后应创建或进入检测任务。
- 机器停止后应停止采集、推理和剔除输出。
- 数据源为 `X 光相机` 时，机器启动后监听 X 光采集链路，异常结果可联动剔除设备。
- 数据源为 `本地图片目录` 时，机器启动后按固定节拍读取目录图片，创建离线检测任务，不输出硬件剔除动作。
- 两种数据源都按当前启用通道绑定的产品、模型和阈值进行检测。
- 机器运行期间禁止切换数据源。
- 机器运行期间禁止切换当前启用通道。

管理员登录时额外显示：

- 修改管理员密码。

- 显示当前账号。

## 7. 数据中心功能规格

数据中心用于查看历史生产数据，不作为实时监控主页面。

### 7.1 顶部筛选

可见控件：

- 海鲜产品下拉框。
- 过去 1 天。
- 过去 7 天。
- 过去 30 天。

功能要求：

- 海鲜产品下拉框应包含系统中所有海鲜产品。
- 若某个产品在当前时间范围内没有检测记录，则图表显示为空状态。
- 时间筛选影响历史统计、检测任务记录和趋势图。

### 7.2 历史统计页签

显示内容：

- 良率环形图。
- 缺陷数量排行。
- 良率趋势分析。

功能要求：

- 良率环形图显示正常与剔除占比。
- 缺陷数量排行展示各缺陷类别数量。
- 良率趋势以检测任务为横坐标，例如 `06-16 #1`、`06-16 #2`。
- 点击趋势图上的检测任务点，可进入检测任务记录查看详情。

### 7.3 检测任务记录页签

显示内容：

- 检测任务编号。
- 任务类型：生产检测 / 离线检测。
- 检测海鲜产品。
- 模型版本。
- 开始时间。
- 结束时间。
- 检测总量。
- 正常数量。
- 异常数量。
- 真实剔除命令数。
- 良率。
- 任务状态。

功能要求：

- 检测任务记录是数据中心的主要明细对象。
- 点击检测任务可查看该任务的正常/剔除占比和缺陷分布。
- 离线检测任务应显示异常数量和缺陷分布，但剔除命令显示为未启用硬件剔除。

### 7.4 异常剔除复核与模型评估

当前版本先对模型判定为异常的剔除集合 `S` 进行人工复核。

复核对象：

- 当前检测任务中所有非正常检测框。
- 模型判定标签，例如 `碎壳`、`泥包`、`空壳`。
- 检测图片路径、置信度和框位置。

人工复核结果：

- 确认异常：人工认为模型判定为异常是正确的。
- 误剔：人工认为该目标实际为正常。
- 类别修正：人工认为该目标确实异常，但异常类别与模型判定不同。

可计算指标：

- 异常确认率 = 已复核确认异常数量 / 已复核数量。
- 误剔率 = 已复核误剔数量 / 已复核数量。
- 类别修正数量。

暂不严格计算的指标：

- 严格召回率。

说明：

- 召回率需要知道漏检数量，即实际异常但模型未判为异常的样本。
- 由于非异常集合数量很大，当前第一版只复核异常集合 `S`，因此无法严格计算召回率。
- 后续如需估计召回率，应增加“未剔除集合抽检”或“漏检登记”功能。

### 7.5 报表与追溯页签

当前定位：

- 下一版本接入。

后续计划：

- 异常图片追溯。
- 检测任务报表导出。
- 按日期、产品、模型筛选导出。

## 8. 设置页功能规格

设置页仅管理员可见。

### 8.1 产品设置

二级模块：

- 海鲜产品。
- 模型管理。
- 通道配置。

#### 8.1.1 海鲜产品

可见按钮：

- 添加产品。
- 预览。
- 编辑。
- 删除。
- 返回产品列表。
- 保存海鲜产品。
- 新增缺陷项。
- 删除缺陷项。
- 取消并返回。

功能要求：

- 查看海鲜产品列表。
- 新增、编辑、删除海鲜产品。
- 预览海鲜产品详情。
- 维护产品名称。
- 维护正常项和缺陷项。
- 新增海鲜产品时必须导入类别标签文件。
- 新增海鲜产品时必须完成类别标签与业务性状的一一映射。
- 编辑已有海鲜产品时，可在类别文件或映射规则发生变化时更新类别标签文件和映射关系。
- 保存产品后返回产品列表。
- 取消编辑时返回产品列表，不保存未提交修改。
- 产品删除失败时显示具体原因。

类别标签文件说明：

- 类别标签文件用于描述 YOLO 模型训练时的类别顺序，典型文件形式为 `classes.txt`。
- 系统读取类别标签文件后，应按文件行号生成模型类别编号，并由管理员将每个类别标签映射到当前海鲜产品的业务性状。
- 类别标签文件属于产品/模型配置资产，不是操作员可见的业务概念。
- 新增海鲜产品时，类别标签文件和类别标签与业务性状映射均为必填配置；未完成映射的产品不能用于生产检测。
- 编辑海鲜产品时不要求每次都导入类别标签文件；若产品已经存在有效映射，且模型类别顺序和业务性状未发生变化，可以保留原映射不变。
- 当模型训练类别、类别顺序、产品性状定义发生变化，或需要重新维护类别映射时，应更新类别标签文件或映射关系。

#### 8.1.2 模型管理

可见按钮：

- 添加模型。
- 预览。
- 编辑。
- 删除。
- 返回模型列表。
- 编辑模型。
- 删除模型。
- 取消返回。

可见筛选：

- 海鲜类别筛选。

功能要求：

- 查看模型列表。
- 按海鲜类别筛选模型。
- 新增、编辑、删除模型。
- 导入 YOLO 模型权重文件。
- 模型绑定海鲜产品。
- 模型版本编号由系统按产品前缀和序列号生成，用于展示和区分模型版本。
- 编辑模型描述和权重路径。
- 查看模型详情。
- 删除未被通道绑定的模型。
- 保存模型后返回模型列表。
- 取消编辑时返回模型列表，不保存未提交修改。

约束：

- 被通道使用的模型不可删除。
- 删除失败时显示具体原因。

#### 8.1.3 通道配置

可见按钮：

- 添加通道。
- 预览。
- 编辑。
- 删除。
- 返回通道列表。
- 保存通道。
- 编辑通道。
- 删除通道。
- 取消并返回。

可见筛选：

- 通道名称搜索。
- 海鲜产品筛选。

功能要求：

- 查看通道列表。
- 按通道名称搜索。
- 按海鲜产品筛选。
- 新增、编辑、删除通道。
- 预览通道详情。
- 通道绑定海鲜产品。
- 通道绑定模型。
- 设置置信度阈值。
- 启用或停用通道。
- 保存通道后返回通道列表。
- 取消编辑时返回通道列表，不保存未提交修改。
- 机器运行期间不可切换通道。
- 删除失败时显示具体原因。

设计说明：

- 通道用于选择产品、模型和推理阈值。
- 传送带速度不是通道字段，应归入整机/硬件运行参数。
- 剔除方式和剔除位不在通道页维护，应进入剔除设置页。

### 8.2 硬件设置

二级模块：

- 设备管理。

可见按钮：

- 刷新设备。
- 新增设备。
- 保存设备。
- 删除。

功能要求：

- 维护 X 光光源。
- 维护 X 光探测器。
- 维护传送带。
- 维护剔除设备。
- 查看设备编号、设备名称、设备类型、固件版本、设备状态。
- 支持设备自检或状态刷新。

真实硬件接入说明：

- X 光探测器可通过厂商 SDK、GigE Vision、GenICam、Camera Link、CoaXPress、USB3 Vision 等方式接入。
- PLC/设备状态可通过 Modbus TCP、OPC UA、PROFINET、EtherNet/IP 或厂商协议接入。
- 当前软件应保留统一硬件适配层，避免业务功能直接绑定某一家设备 SDK。

### 8.3 剔除设置

二级模块：

- 剔除控制。
- 安全预警。

#### 8.3.1 剔除控制

可见按钮：

- 保存。

功能要求：

- 维护剔除方式。
- 维护剔除位。
- 维护气吹、推杆、翻板、下沉等剔除动作参数。
- 后续接入剔除设备后，可将参数下发至 PLC 或剔除控制器。

#### 8.3.2 安全预警

可见按钮：

- 刷新预警。
- 确认选中预警。

功能要求：

- 显示当前未确认预警。
- 显示硬件联锁状态。
- 显示阻断运行的关键设备异常。
- 支持确认选中预警。

联锁要求：

- X 光光源异常，系统应进入故障状态。
- X 光探测器异常，系统应进入故障状态。
- 传送带异常，系统应进入故障状态。
- 剔除设备异常，系统应进入故障状态。
- 严重硬件故障未确认或未恢复时，不允许机器正常运行。

### 8.4 系统设置

二级模块：

- 安全预警。
- 软件维护。
- 设备管理。

## 10. 真实 X 光采集与当前调试入口的关系

当前首页可见的 `数据源配置` 用于明确图像来源：

- `X 光相机`：默认生产数据源，代表真实 X 光探测器或工业相机采集链路。
- `本地图片目录`：离线检测数据源，用于在没有真实 X 光探测器时验证算法和软件流程，也可用于后续对一批图片主动选择通道进行批量检测。

两种数据源都会创建检测任务、调用 YOLO、写入检测记录和统计数据。区别在于：`X 光相机` 模式允许联动剔除设备；`本地图片目录` 模式只做检测分析，不生成、不执行真实剔除动作。

正式生产时，图像来源应改为真实 X 光采集链路：

```text
X 光探测器 / 工业相机
        ↓
厂商 SDK / GigE Vision / GenICam / Camera Link / CoaXPress
        ↓
X 光图像采集服务
        ↓
YOLO 推理服务
        ↓
首页图像展示、分类统计、检测任务记录、剔除控制
```

功能要求：

- 机器启动后自动开始监听或采集 X 光图像。
- 每张图像进入当前检测任务。
- 每张图像按当前启用通道绑定的海鲜产品和模型进行检测。
- 机器运行中不允许切换数据源。
- 本地图片目录检测任务应明确标识为离线检测。
- 图像采集异常应触发安全预警。
- 关键硬件异常时不允许继续运行。

## 11. 验收口径

### 11.1 甲方界面验收

- 左侧导航能看到：首页、用户、数据、设置、退出系统。
- 首页能看到 X 光图像区域、当前图片识别结果、分类统计、状态记录和主控操作台。
- 首页能通过一个状态按钮操作机器启动和机器停止。
- 首页能看到数据源配置，默认数据源为 X 光相机。
- 首页能切换本地图片目录作为离线检测数据源，机器运行中不能切换数据源。
- 数据中心能按海鲜产品和时间范围查看统计。
- 数据中心能从检测任务记录进入异常集合人工复核界面。
- 用户中心能查看当前用户和权限范围。
- 管理员能进入设置页。
- 操作员不能进入设置页。
- 设置页能看到产品设置、硬件设置、剔除设置、系统设置。

### 11.2 功能数据验收

- 海鲜总数 = 正常数量 + 异常总数。
- 异常总数 = 各缺陷类别数量之和。
- 良率 = 正常数量 / 海鲜总数。
- 识别标签按海鲜产品映射显示，不显示 `class_0`。
- 检测任务记录中能看到任务类型、检测产品、模型版本、检测总量、异常数量、真实剔除命令数和良率。
- 本地图片目录任务不输出真实剔除命令，但应正常统计检测总量、异常数量和良率。
- 检测任务详情中能对异常集合 `S` 做人工复核，并计算异常确认率和误剔率。
- 系统不应在未复核未剔除集合时宣称已得到严格召回率。

### 11.3 硬件联锁验收

- X 光光源、X 光探测器、传送带、剔除设备属于关键硬件。
- 关键硬件异常时页面应红色告警。
- 关键硬件异常时系统不允许正常运行。
- 告警信息可在安全预警页查看和确认。
