## 离线检测使用方法

1. 打开上面的链接，将“数据集”保存到网盘并下载、解压；
2. 在软件中创建产品、导入对应模型并启用通道；
3. 回到主控工作台，将数据源切换为“离线图片”；
4. 选择包含图片的类别目录，例如 `数据集\youge\normal`；
5. 开始检测并查看图片、检测框、类别、置信度和统计结果。

软件当前读取所选目录第一层的 PNG、JPG、JPEG 和 BMP 文件，不递归读取子目录。因此不能直接选择 `youge` 根目录；应选择其下的 `broken`、`empty`、`muddy` 或 `normal` 目录。需要一次检测多个类别时，可以先将这些类别目录中的图片复制到同一个新目录，再选择该目录。

当前仓库包含油蛤模型权重，可以直接使用 `youge` 数据完成推理演示。花蛤和美贝数据已经提供，但仍需导入与产品匹配的模型权重后才能得到有效预测结果。

离线模式只执行图片分析与结果记录，不会向现场剔除设备发送控制命令。
