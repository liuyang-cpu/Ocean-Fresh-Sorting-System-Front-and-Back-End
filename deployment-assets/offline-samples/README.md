# 离线检测演示图片

本目录包含从本地数据集中抽取的离线检测演示图片，可直接在软件主页面选择对应产品目录进行批量检测。

## 目录说明

- `huage`：花蛤，共 12 张，覆盖 `broken / empty / normal / sandy`；
- `meibei`：美贝，共 12 张，覆盖 `broken / empty / muddy / normal`；
- `youge`：油蛤，共 12 张，覆盖 `broken / empty / muddy / normal`。

每个类别抽取 3 张原始 PNG 图片。文件名前缀表示图片所属类别，例如 `broken_*.png`。

## 使用方法

1. 在软件中创建产品、导入对应模型并启用通道；
2. 回到主控工作台，将数据源切换为“离线图片”；
3. 选择本目录下对应产品文件夹，例如 `deployment-assets\offline-samples\youge`；
4. 开始检测并查看图片、检测框、类别、置信度和统计结果。

当前仓库包含油蛤模型权重，可直接使用 `youge` 图片完成推理演示。花蛤和美贝图片已经提供，但仍需导入与产品匹配的模型权重后才能得到有效预测结果。

离线模式只执行图片分析与结果记录，不会向现场剔除设备发送控制命令。
